# Code of conduct

Prio is a small project maintained on free time. Keep the discussion about the
code and the idea, be patient with a slow answer, and assume good faith.

## Not acceptable

- insults, personal attacks, harassment, discrimination
- publishing someone else's private information
- anything that would not be said to a colleague

## Enforcement

The maintainer may edit or remove comments, issues and pull requests, and block
a contributor who keeps breaking these rules. To report a problem, contact
[@BBellenoue](https://github.com/BBellenoue) on GitHub.

This applies to the issues, pull requests and discussions of this repository.
